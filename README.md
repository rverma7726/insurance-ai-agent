# 🏦 Insurance AI Agent - Agentic AI Platform

**Autonomous AI system for insurance policy analytics and customer retention using Claude extended thinking + Model Context Protocol (MCP)**

![Status](https://img.shields.io/badge/status-production-green)
![License](https://img.shields.io/badge/license-MIT-blue)

## 🎯 What This Does

✅ **Captures life events** from customers (travel, vehicle changes, renovations)
✅ **Analyzes policies** autonomously using Claude extended thinking
✅ **Predicts renewal needs** 60 days in advance
✅ **Recommends coverages** based on usage patterns and life events
✅ **Generates retention offers** with personalized gift vouchers
✅ **Scores churn risk** and prevents customer loss
✅ **Scales to millions** of customers with $0 API costs (free Claude tier)

## 🚀 Quick Start

### Prerequisites
- Node.js 18+
- PostgreSQL 12+
- Claude API key (free: $5 credits)

### Installation

```bash
# Clone repository
git clone https://github.com/rverma7726/insurance-ai-agent.git
cd insurance-ai-agent

# Install dependencies
npm install
cd backend && npm install && cd ..
cd mcp-server && npm install && cd ..
cd frontend && npm install && cd ..

# Configure
cp .env.example .env
# Add your Claude API key to .env

# Start
docker-compose up -d
npm start
